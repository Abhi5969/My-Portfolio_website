# Abhinandan Maity — Portfolio Website

## Files
- `index.html` — semantic HTML5 page and all portfolio sections
- `style.css` — responsive styling
- `script.js` — mobile navigation and contact form behavior

## Run locally
Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Before publishing
1. Open `script.js` and replace `your-email@example.com` with your real email address.
2. Replace the sample workspace image in `index.html` with your own profile photo if desired. Keep useful alt text.
3. Review the skills list and remove technologies you have not used.
4. Update project descriptions to match what each repository actually does.
5. Test on mobile, tablet, and desktop.

## Contact form note
The form validates the required fields in the browser and prepares an email using `mailto:`. It opens the visitor's email application; it does not send messages through a server. For direct website submissions without an email app, connect a form backend/service (for example, Formspree) or build your own backend endpoint.
